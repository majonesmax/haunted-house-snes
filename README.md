# Haunted House: By Matchlight (Super Nintendo)

Atari 2600 *Haunted House*, rule for rule, as a native Super Nintendo game - the
[NES game](https://github.com/majonesmax/haunted-house-nes)'s mansion, with the
[remaster](https://github.com/majonesmax/haunted-house-remastered)'s SNES look and its orchestra.

In progress: the engine runs - the whole game, in C, checked frame by frame against the remaster's model
of the original - and the picture is in: the floors, the cast, the match's light, the status band. No sound
yet, and no screens. See [the plan](docs/plan.md).

## Playing

The pad is the 2600's joystick: the D-pad moves, A or B is the button (lights a match; drops what's held),
Start is RESET and Select is SELECT. With the button held, Select turns the lights on and off instead (the
remaster's cheat: the whole floor lit, everything on it shown where the game has it); the game is unchanged
by it.
