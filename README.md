# Haunted House: By Matchlight (Super Nintendo)

Atari 2600 *Haunted House*, rule for rule, as a native Super Nintendo game - the
[NES game](https://github.com/majonesmax/haunted-house-nes)'s mansion, with the
[remaster](https://github.com/majonesmax/haunted-house-remastered)'s SNES look and its orchestra.

Just begun: the engine runs - the whole game, in C, checked frame by frame against the remaster's model of
the original - and nothing is drawn yet. See [the plan](docs/plan.md).
